# autoautodl v1.0.0 · 首个正式版

提供 Windows 安装版与便携版，统一使用 autoautodl 名称和图标。

## 下载

- **autoautodl-1.0.0-Setup.exe（推荐）**：安装向导、可选安装目录、桌面和开始菜单快捷方式、Windows 卸载入口。
- **autoautodl-1.0.0-Windows.exe**：便携版，直接运行。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

## 功能与修复

- 首页统一仅开机、仅克隆、开机或克隆三种模式，只获取一台；新建实例单独配置。
- 共享登录、余额缓存、动态 GPU 监控台、资源仪表、账单与消息中心。
- 完成通知支持桌面、AutoDL 微信及 Webhook，提供配置引导。
- 修复普通后台同步导致“开始排队”不可点击；显示具体禁用原因。
- 已暂停旧克隆有明确目标回执且重新核实为关机时，自动归档并解除单台锁；未知、运行中或启动中的目标不会被自动解锁。
- 增加只读核实与结束旧候补入口，保留历史回执、云端实例和磁盘；不会在解锁后擅自启动新的付费任务。

## 升级说明

从托盘退出旧版本后安装或运行新版。数据继续使用 `%APPDATA%\autodl-companion`，无需迁移；卸载默认保留设置和会话。程序目前未签名。

436 项自动化测试通过。此前完成本地打包启动与界面检查；自动化验证不替代真实账号下的计费验收，平台接口和页面变化仍可能影响功能。
